**Descripción:**

Este repositorio reúne una serie de cuadernos desarrollados con el objetivo de introducir y consolidar los fundamentos del lenguaje de programación **Python**. A lo largo del trabajo se abordan los principales tipos de datos, estructuras de datos, mecanismos de control de flujo, funciones y nociones básicas de programación orientada a objetos.

El repositorio tiene como propósito fortalecer el **pensamiento lógico y computacional**, proporcionando una base teórica y práctica que permita comprender el funcionamiento de Python y desarrollar las habilidades necesarias para su aplicación en el área de **Procesamiento de Alto Volumen de Datos** y en nuestra formación como futuros profesionales.
